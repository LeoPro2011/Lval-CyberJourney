## ARP and ICMP

- **ARP (Address Resolution Protocol)** is used on an IPv4 local network to discover the MAC address associated with an IPv4 address. This helps a device send an Ethernet frame to the correct device on the local network.
- **ICMP (Internet Control Message Protocol)** carries error and diagnostic information related to IP networking. Tools such as `ping` use ICMP to test reachability when the relevant traffic is not filtered.

## Routing and routing protocols

**Routing** allows routers to decide where to forward packets so that they can reach a destination network. I was introduced to several routing protocols:

- **OSPF (Open Shortest Path First):** a link-state routing protocol used within an autonomous system. Routers share topology information and calculate paths using link costs.
- **EIGRP (Enhanced Interior Gateway Routing Protocol):** a Cisco-developed routing protocol, historically proprietary, that calculates routes using metrics such as bandwidth and delay. It is often described as an advanced distance-vector protocol.
- **BGP (Border Gateway Protocol):** exchanges routing information between autonomous systems. It is central to routing between networks on the Internet; route selection is also influenced by routing policies, not simply the shortest path.
- **RIP (Routing Information Protocol):** a simple distance-vector protocol that uses hop count as its metric. Its classic limit is 15 hops; 16 is treated as unreachable.

This introduction helped me distinguish routing within an administrative network from exchanging routes between independent networks.

## DHCP and NAT

I also reviewed **DHCP**, which automatically provides devices with network configuration such as an IP address, subnet mask, default gateway, and DNS servers.

I learned about **NAT (Network Address Translation)**, which translates IP addresses between networks. A common home or business setup uses **PAT/NAT overload**: multiple devices with private IPv4 addresses share one public IPv4 address by translating port numbers. Not every form of NAT necessarily uses a single public address.
