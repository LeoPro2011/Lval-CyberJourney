# TryHackMe — Journal de progression
## 18 octobre 2026 — Pre Security

Aujourd'hui, j'ai avancé dans le parcours **Pre Security** et terminé plusieurs modules introductifs. Cette journée m'a surtout permis de consolider une vision globale des systèmes, du réseau, du cloud et des bases du développement.

### Modules et rooms signalés comme terminés

- **Database SQL Basics** — premières notions de bases relationnelles (tables, colonnes, lignes) et rédaction d'une première requête SQL.
- **What Is Networking?** — introduction aux fondamentaux réseau.
- **Computer Types** — aperçu des catégories de systèmes informatiques.
- **Client-Server Basics** — compréhension du modèle client-serveur.
- **Windows CLI Basics** — premières commandes dans l'invite de commandes Windows.
- **Cloud Computing Fundamentals** — découverte globale du cloud et des modèles de service.
- **Python: Simple Demo** — démonstration introductive, très accessible compte tenu de mes bases préalables en Python.
- **JavaScript: Simple Demo** — démonstration introductive ; je comprends les bases, mais je dois encore m'entraîner à écrire du JavaScript moi-même.
- **Linux CLI Basics** — révision des commandes de base Linux.
- **Virtualization Basics** — introduction à la virtualisation.
- **Operating System Security** — notions introductives de sécurité des systèmes d'exploitation.
- **Linux Fundamentals 1, 2 et 3** — parcours terminé ; badge obtenu.

### Ce que je retiens

- Une base de données relationnelle organise les données en tables ; SQL permet d'interroger ou de modifier ces données selon les droits disponibles.
- Le modèle client-serveur et les bases réseau sont indispensables pour comprendre le fonctionnement des applications web.
- Le cloud implique aussi de comprendre les modèles de service, les ressources, la virtualisation et les coûts.
- Le CLI Windows est utile pour le support informatique et deviendra important pour l'administration Windows et la compréhension d'Active Directory.
- Les démonstrations Python et JavaScript étaient principalement des révisions ; les prochaines étapes devront privilégier la pratique autonome.

### Suite

Je poursuis **Pre Security** pour consolider les fondamentaux avant de continuer vers Cyber Security 101, puis des parcours plus ciblés en SOC/DFIR, sécurité web et sécurité de l'IA.
