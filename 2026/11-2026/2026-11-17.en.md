## TryHackMe — MD2PDF

Completed room: [MD2PDF](https://tryhackme.com/room/md2pdf).

The application converts Markdown into PDF files. During enumeration, I found an `/admin` page that denied direct access and stated that it was only accessible from `localhost:5000`. I then used the PDF conversion engine's behaviour to retrieve the contents of this internal page in the generated document.

### Main concept: SSRF

A **Server-Side Request Forgery (SSRF)** occurs when an attacker makes a server perform a request on their behalf. In this case, the PDF converter could access a local resource that my browser could not reach directly. The administration page's contents were then displayed in the generated PDF.

**Key takeaway:** a feature that fetches or renders resources based on user-supplied input can become an indirect route to internal services if its requests are not properly restricted.
