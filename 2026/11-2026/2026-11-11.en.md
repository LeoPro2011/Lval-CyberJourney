## John the Ripper

The room introduced me to **John the Ripper**, a password-recovery tool that tests candidate passwords against hashes. I worked on identifying hash formats and encountered several hash families in the exercises: MD5, SHA-256, Whirlpool, and Windows authentication formats such as NTLM.

## Linux hashes and the shadow file

I learned how account hashes are stored in a copy of Linux's `/etc/shadow`, and how to prepare the data with `unshadow`, which combines information from `/etc/passwd` and `/etc/shadow`. I then used John with a wordlist to test candidate passwords. This also helped me distinguish the file containing password hashes from the file containing candidate passwords.

## Single Crack Mode, word mangling and GECOS

I explored John's `--single` mode. Rather than relying only on an external wordlist, this mode uses account-related information—especially the username and GECOS field—to generate likely password variations. I learned the concepts of *word mangling* and rule-based transformations.
