## Projet personnel — Installation de PentestGPT

J'ai également avancé sur l'installation de **[PentestGPT](https://github.com/GreyDGL/PentestGPT)** dans Kali Linux sous WSL.

- Clonage du dépôt avec ses sous-modules et installation des dépendances avec `uv` et `make install`.
- Installation native de **Codex CLI** sous Linux (version 0.169.0), après avoir corrigé un problème lié à une installation npm qui pointait vers Windows.
- Configuration de Codex pour utiliser **OpenRouter** avec le modèle gratuit **NVIDIA Nemotron 3 Ultra 550B** via `~/.codex/config.toml`.
- Test de connexion avec `codex exec` : le modèle a bien répondu « OK ».
- Inspection du backend de PentestGPT : l'agent utilise le SDK `openai-codex` (version 0.1.0b3) via `codex app-server`.

L'intégration effective d'OpenRouter dans le SDK utilisé par PentestGPT reste à confirmer. J'ai aussi identifié que les rôles superviseur et exécutant sont configurés en `FULL_ACCESS`. **Aucun pentest autonome n'a été lancé** : il reste à vérifier l'authentification et à mettre en place une isolation adaptée avant tout essai.
