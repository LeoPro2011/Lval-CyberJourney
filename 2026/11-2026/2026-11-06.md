Rien de particulièrement nouveau dans les manipulations, mais le tableau récapitulatif des options constitue une référence très utile pour retrouver rapidement les paramètres selon le type de scan ou l'information recherchée.

### Tableau récapitulatif des options Nmap

| **Option** | **Explication** |
| :-- | :-- |
| `-sL` | List scan : liste les cibles sans effectuer de scan. |
| **Host Discovery** | |
| `-sn` | Ping scan : découverte des hôtes uniquement. |
| **Port Scanning** | |
| `-sT` | TCP connect scan : établit une connexion TCP complète (three-way handshake). |
| `-sS` | TCP SYN scan : envoie le premier paquet du three-way handshake sans établir une connexion complète. |
| `-sU` | Scan des ports UDP. |
| `-F` | Fast mode : scanne les 100 ports les plus courants. |
| `-p[range]` | Définit les ports à scanner ; `-p-` couvre tous les ports. |
| `-Pn` | Considère toutes les cibles comme actives, même si elles semblent hors ligne. |
| **Service Detection** | |
| `-O` | Détection du système d'exploitation. |
| `-sV` | Détection des versions des services. |
| `-A` | Active notamment la détection de l'OS et des versions, ainsi que d'autres fonctionnalités. |
| **Timing** | |
| `-T<0-5>` | Définit le profil de vitesse : paranoid (0), sneaky (1), polite (2), normal (3), aggressive (4), insane (5). |
| `--min-parallelism <numprobes>` / `--max-parallelism <numprobes>` | Définit le nombre minimal et maximal de sondes parallèles. |
| `--min-rate <number>` / `--max-rate <number>` | Définit le débit minimal et maximal de paquets par seconde. |
| `--host-timeout` | Définit le temps maximal d'attente pour une cible. |
| **Real-time output** | |
| `-v` | Augmente le niveau de verbosité (ex. : `-vv`, `-v4`). |
| `-d` | Augmente le niveau de débogage (ex. : `-d`, `-d9`). |
| **Report** | |
| `-oN <filename>` | Enregistre la sortie au format normal. |
| `-oX <filename>` | Enregistre la sortie au format XML. |
| `-oG <filename>` | Enregistre la sortie dans un format exploitable avec grep. |
| `-oA <basename>` | Enregistre les résultats dans les principaux formats. |

Ce tableau me servira de mémo pour les prochaines utilisations de Nmap.
