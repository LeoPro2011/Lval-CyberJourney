### Nmap options reference

| **Option** | **Explanation** |
| :-- | :-- |
| `-sL` | List scan: lists targets without scanning them. |
| **Host Discovery** | |
| `-sn` | Ping scan: host discovery only. |
| **Port Scanning** | |
| `-sT` | TCP connect scan: completes the TCP three-way handshake. |
| `-sS` | TCP SYN scan: sends the first step of the three-way handshake without completing a full connection. |
| `-sU` | UDP scan. |
| `-F` | Fast mode: scans the 100 most common ports. |
| `-p[range]` | Specifies the ports to scan; `-p-` scans all ports. |
| `-Pn` | Treats all targets as online, even if they appear to be down. |
| **Service Detection** | |
| `-O` | Operating system detection. |
| `-sV` | Service version detection. |
| `-A` | Enables OS and version detection, along with other features. |
| **Timing** | |
| `-T<0-5>` | Sets the timing template: paranoid (0), sneaky (1), polite (2), normal (3), aggressive (4), insane (5). |
| `--min-parallelism <numprobes>` / `--max-parallelism <numprobes>` | Sets the minimum and maximum number of parallel probes. |
| `--min-rate <number>` / `--max-rate <number>` | Sets the minimum and maximum packet rate per second. |
| `--host-timeout` | Sets the maximum time to wait for a target host. |
| **Real-time output** | |
| `-v` | Increases verbosity (e.g. `-vv`, `-v4`). |
| `-d` | Increases debugging level (e.g. `-d`, `-d9`). |
| **Report** | |
| `-oN <filename>` | Saves output in normal format. |
| `-oX <filename>` | Saves output in XML format. |
| `-oG <filename>` | Saves output in a grep-friendly format. |
| `-oA <basename>` | Saves results in all major formats. |

This table will be useful as a quick reference for future Nmap work.
