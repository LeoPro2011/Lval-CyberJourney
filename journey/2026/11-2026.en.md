### 01/11/2026 — Corridor

I completed **Corridor**, a web room focused on an IDOR vulnerability. By inspecting the URLs, I identified MD5 hashes corresponding to predictable numeric identifiers. Testing the value 0 as a hash in the URL exposed a hidden resource containing the flag. The room demonstrates that obfuscating an identifier is no substitute for server-side access control.

Detailed journal: [1 November journal](../../2026/11-2026/2026-11-01.en.md).


### 01/11/2026 — Agent T

I completed **Agent T**, a web room where inspecting HTTP headers revealed **PHP 8.1.0-dev**. I identified the backdoor associated with this version, which could be triggered through the custom `User-Agentt` header. Using `curl`, I sent a request containing `system('cat /flag.txt')`, then used `grep` to isolate the flag from the HTML response. Topics practiced: HTTP headers, custom requests, RCE, and command-line filtering.

## 10/11/2026 — Hashing Basics and LLM exploration

I completed **[Hashing Basics](https://tryhackme.com/room/hashingbasics)**.
